# PLY Lite

A lightweight music player focused on simplicity.

## Concept

PLY Lite plays audio files opened by the user and allows navigation between other audio files in the same folder.

## Main Features

- Open and play an audio file.
- Automatically detect other supported audio files in the same folder.
- Navigate to the previous and next tracks in that folder.
- Simple playback controls.
- Display the current track information.

## Design

PLY Lite aims to provide a clean and minimal interface, based on the supplied UI reference.

## Scope

PLY Lite is designed for simple, folder-based music playback. It does not aim to provide a global music library or advanced music management features.
